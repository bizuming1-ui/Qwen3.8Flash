QTTS · 双 T4 声音台 原站字节级复刻

              

                你粘贴的 Kaggle 单 cell 代码里内嵌了 70 个 SHA-256 校验过的源码资产，其中
                web/index.html · app.js · recorder.js ·
                diagnostic-trace.js 构成了「QTTS 声音台」网站。
                本项目把这四个文件原封不动解包到 replica/web/ 并在
                /site/ 提供，配合 Node 实现的完全兼容后端（Go gateway + Python analyst 的 38 个接口），
                使网站所有功能在本地都能操作。

            声音档案 / 声音库 / 原始样本 / 训练输入快照 / 双卡短测 / 脱敏诊断导出 / 录音与 WAV 下载。
            
没有复刻什么：真实 Qwen-TTS 模型权重、双 T4 GPU 推理、Whisper/DeepSeek 调用。

            quality_verified:false / simulated:true。

🔌 QTTS 网关 API 兼容矩阵

              
原始系统：Go gateway (:7860) 反向代理到 Python FastAPI analyst (:7010) + 两个 worker (:7001/:7002)。
                本地复刻把这套契约完整实现在 Node 里，前端 web/app.js 无需任何改动即可调用。

          

          

          

        


        
        

          

            
🔬 精准对照实验室

              
把 Kaggle 源码里的核心算法逐行移植到 Node，再在浏览器里逐项对照：
                go/gateway/segmenter.go 的呼吸组分段、
                py/step18_audio_rt.py + py/worker.py 的五种音量策略、
                go/gateway/monitor.go 的脱敏白名单、
                go/gateway/security.go 的准入限流，以及 worker → gateway → 浏览器的双层二进制帧。
                波形仍是明确标注的合成音（本沙盒无模型权重 / GPU / DeepSeek Key），但分段、增益、限幅、协议与落盘布局都是原算法的等价实现。

② Python DSP · 五种音量路径对照

                共同输入：2.00 s / 48000 samples
